## API/core

- **Add `llama_ftype_name()` public API** -- exposes the model file-type
  (quantization) name (e.g. "Q4_K - Medium") as a null-terminated string valid
  for the lifetime of the model; the function is allocation-free and
  thread-safe. Also adds `LLAMA_FTYPE_PREFIX` and surfaces the ftype in the
  CLI startup banner and server context. (#25134, `fdb1db8`)
