# llama.cpp daily summary -- 2026-07-04

Active day with 10 commits: a mix of CUDA performance work, UI feature additions, a server reliability fix, and dependency maintenance. No breaking changes; two notable performance-oriented CUDA improvements landed.

## CUDA/GPU

- **topk-moe fusion extended to 288 experts** (#25267, `75a48a9`): enables the existing fused kernel for models with 288 experts (e.g. Step-3.7-Flash), yielding ~2.4% decode throughput gain at shallow context. Prompt processing unaffected.
- **Remove redundant copies after gated_delta_net** (#23940, `5a460de`): detects the `gated_delta_net -> view -> cpy` graph pattern and writes state snapshots directly into the recurrent cache, eliminating up to K extra `ggml_cuda_cpy` calls per token in MTP-decode mode.

## API/Server

- **SSE keep-alive fix** (#25241, `b5315e1`): server now pings silent SSE streams every 1s and only drops the connection after 3s of silence, preventing healthy connections from being torn down during slow prefill. `sse_ping_interval` is now a typed per-request body field; the global CLI default stays at 30s so non-UI clients are unaffected.

## Speculative Decoding

- **DFlash spec-draft-p-min support** (#25246, `152d337`): adds `n_min`/`n_max` guards so the `--draft-p-min` threshold is honoured in DFlash mode.

## UI

- **MCP Servers opt-in dialog for first-time visitors** (#25239, `9487528`): new onboarding dialog shows recommended MCP servers; includes tests and migration logic. Large change (~1,400 lines net).
- **SSE streaming performance** (#25225, `d4cff11`): sibling info map now built once per structural change instead of on every render tick, reducing streaming jank.
- **Thinking enabled by default** (#25242, `067de93`): new and legacy conversations without a saved preference now default to thinking mode on.
- **Model ID display cleanup** (#25137, `f113e02`): strips file path and weight extension from model IDs in single-model mode.

## Chat / Templates
