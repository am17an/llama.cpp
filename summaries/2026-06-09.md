# llama.cpp daily summary -- 2026-06-09

Active day with 16 commits landing across GPU backends, multimodal support, server fixes, and a notable ggml version bump to 0.14.0. The headline addition is video input support in the multimodal (mtmd) layer, and WebGPU saw multiple performance and correctness improvements.

## Notable new feature

- **mtmd: video input support** -- extends the multimodal helper to accept video frames via ffmpeg, wires it into the server and CLI, and adds a C API test. Docker images now include ffmpeg. (#24269, `8f83d6c`)

## WebGPU

- Improved prefill speeds for k-quants; refactored matmul shaders for Q4/Q5/Q8 and all k-quant types (~800-line shader reduction) (#24225, `1e1aca0`)
- Implemented 2D workgroups for scale, binary, and unary ops for better GPU utilization (#24044, `3b3da01`)
- Fixed buffer overlap/aliasing for the concat operator (#24000, `1705d43`)
