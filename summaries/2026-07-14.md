# llama.cpp daily summary -- 2026-07-14

A busy day with 11 commits spanning new model support, major GPU backend refactors, and UI improvements. The standout addition is full Tencent Hunyuan 3 (hy_v3) model support; CUDA MMQ kernels also received a significant structural overhaul.

## Models

- **New model: Hy3 (hy_v3) -- Tencent Hunyuan 3** with MTP speculative decoding support; includes MoE decoder, per-head Q/K RMSNorm, sigmoid router with expert-selection bias, and a shared always-active expert. Adds conversion script, Jinja template, and arch registration. (#25395, `2969d6d`)
- **spec:** Fixed a nullptr crash in Minimax2 EAGLE3 speculative decoding path (`259ae1d`)

## CUDA/GPU

- **CUDA:** Refactored MMQ kernel configuration into per-architecture header files (Ampere, Blackwell, CDNA, Pascal, RDNA2/4); splits load-tiles and vec-dot logic into dedicated `.cuh` files. Large cleanup removing ~3500 lines of legacy code. (#24127, `6eddde0`)

## Vulkan

- **Vulkan:** Use native `VK_EXT_shader_ocp_microscaling_types` (e2m1) and fp8 (e4m3) type conversions for mxfp4/nvfp4 dequantization instead of software emulation. Adds feature-test shaders to detect hardware support. (#25338, `e920c52`)

## SYCL

- **SYCL:** Added fused top-k MoE kernel for improved MoE inference throughput. (#25217, `efb3036`)
- **SYCL:** Added Q2_K quantization to the DMMV reorder path, matching parity with other quant types. (#25064, `e474bba`)

## Chat / Inference

- **chat:** Fixed a reasoning "leak" where a force-opened bare `<think>` tag without a matching close caused reasoning content to bleed into the response in affected chat templates. (#24674, `91c631b`)

## GGUF / API

- **gguf:** Added a tensor shape accessor to the GGUF C API, enabling callers to retrieve dimension info without reimplementing layout logic. (#24405, `ad8d821`)

## UI
