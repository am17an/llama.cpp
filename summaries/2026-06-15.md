# llama.cpp daily summary -- 2026-06-15

Today's activity (13 commits) was dominated by mobile UI fixes and Cohere2 MoE (North Code) model support, with scattered CI, build, and tooling improvements. No breaking changes were introduced.

## Chat / Model Support

- **Cohere2MoE (North Code) chat parser**: Added a dedicated Jinja chat template and parser for Cohere2MoE in `common/chat.cpp`, with accompanying tests. (#24615, `aedb2a5`)
- **Cohere2MoE vocab**: Added `cohere2moe` to `llama-vocab.cpp` for the TINY_AYA test fixture so CI can run properly. (#24601, `8ed274e`)

## Web UI / Server UI

- **HEIC/HEIF image upload support**: The server UI now converts HEIC/HEIF images to JPEG on upload via a CDN-loaded library, closing a feature request. (#24137, `5f04dc7`)
- **Thinking block markdown rendering**: Reasoning/thinking block content in chat messages is now rendered as Markdown, with a user-facing toggle in settings. (#24611, `ef8268f`)
- **Mobile UI height clipping fix**: Replaced `h-screen` with flex+100% height to stop content being clipped on Android Chrome and iOS Safari. (#24605, `1fd6dfe`)
- **Mobile keyboard & PWA fixes**: Layout now stays visible above the software keyboard (`dvh`/`interactive-widget`); duplicate PWA "update available" popup is suppressed on non-PWA pages. (#24610, `fd5869f`)

## CLI / Core

- **llama-cli preserved tokens fix**: `llama-cli` was not copying `preserved_tokens` from chat params into sampling params, causing special tokens (e.g., `<|END_THINKING|>`) to be detokenized and corrupt model output. Fixed in `tools/cli/cli.cpp`. (#24258, `6e14286`)

## Jinja / Templates

- **Jinja filter aliases**: Added `count`, `d`, and `e` as filter aliases in the Jinja runtime (`common/jinja/runtime.cpp`). (#24606, `acd79d6`)
- **LoRA convert fix**: `convert_lora_to_gguf.py` was retrieving the base model architecture incorrectly; fixed. (#24621, `dd4623a`)

## Build / CI / Docker

- **Docker registry prefix**: All Dockerfiles now explicitly prefix the base image registry, simplifying Podman builds that don't default to Docker Hub. (#24607, `20c5266`)
- **CI CUDA label fix**: GitHub labeler config now correctly tags PRs touching the CUDA backend. (#24594, `4672211`)
- **SYCL added to release check**: The `check-release` workflow now also validates SYCL builds. (#24583, `c2ba3e4`)

## Docs

- Minor typo fixes in `docs/backend/CUDA-FEDORA.md` and `grammars/README.md`. (#24459, `8edaca9`)
