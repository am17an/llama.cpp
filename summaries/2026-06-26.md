# llama.cpp daily summary -- 2026-06-26

Active day with 18 commits merged to upstream/master, spanning GPU backends (CUDA, SYCL, OpenCL, HIP), Apple platform improvements, a new CLI download subcommand, and several server and model fixes. The standout additions are SYCL tensor-parallelism support and a new `llama download` app subcommand.

## CUDA / GPU

- **CUDA `cpy.cu` overflow fixes**: Multiple integer overflow bugs in the copy kernel corrected -- y-dim fallback relaxed to inclusive bounds, x-guards fixed to allow INT_MAX, and transposed copy overflow addressed; new test cases added (#25000, `1ec44d1`)
- **ggml CUDA binary ops**: Integer overflow in binary ops CUDA implementation addressed via `size_t` casts and added asserts (#24706, `f728ada`)

## SYCL

- **Tensor parallelism (`--split-mode tensor`)**: Ring all-reduce implementation for dual-GPU SYCL setups, with FP32 path for small tensors and BF16-compressed path for large ones. Benchmarked at +20% pp and +78% tg vs. layer mode on Llama-3.3-70B Q4_K_M on dual Intel Arc Pro B70 (#24152, `e9fb3b3`)
- **conv_3d unit test fix**: Resolved failing UT cases for conv_3d in SYCL backend (#24900, `9c10954`)

## OpenCL

- Support non-contiguous rows in the norm kernel (#24965, `fdb2c11`)

## Build / Apple

- **Apple XCFramework libmtmd**: New opt-in `LLAMA_BUILD_MTMD` CMake flag includes `libmtmd.a` (52 `_mtmd_` symbols) in the XCFramework, enabling Swift/Obj-C consumers on iOS/macOS/tvOS/visionOS to use the vision API (#21935, `e12a012`)
- **xcframework**: Disable mtmd video features on i/tv/visionOS to avoid unsupported paths (#25018, `beac530`)

## API / Server / App

- **Server 403 for disabled features**: Endpoints now return HTTP 403 instead of a non-standard code when a feature is disabled (#24970, `e9d1b76`)
- **`llama download` subcommand**: New `app` subcommand for downloading models directly from the CLI (#24982, `683b04c`)
- **chat caps check hardened**: Caps validation made more robust in chat flow (#24973, `09cedfd`)
- **common: model handling refactor**: HF plan logic moved to download module; `--offline` case fixed; `skip_download` option removed (#24980, `60bc886`)
