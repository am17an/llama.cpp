# llama.cpp daily summary — 2026-05-31

Thirteen commits landed on upstream master in the last 24 hours, with a strong focus on GPU backend improvements across Vulkan, OpenCL, and Metal, alongside several CI reliability fixes. Two notable bug fixes address correctness issues with iGPU device selection and Qwen tensor-parallelism granularity.

## CUDA/GPU / Vulkan

- **Vulkan: Flash Attention now supports BFloat16 KV cache** — adds FA BF16 support across scalar, coopmat1, and coopmat2 paths (#23420, `6e093b8`). Notable new capability for BF16-heavy models.
- **OpenCL: BF16 support via host-side f16 conversion** — reduces graph splits for models like Gemma-4 that use BF16 weights (#23839, `d6588da`).

## Metal

- **Restore im2col for large kernels (KH\*KW > 1024)** — the optimized path was dropped in a prior refactor; the fallback is re-enabled for oversized 2D convolution kernels (#23901, `2d9b7c8`).

## CPU / LoongArch

- **Add LSX SIMD support for quantized ops** — native LSX intrinsics for fp16 load/store, q8\_0, q6\_K, and iq4\_xs dot products (#23798, `d48a56e`).

## Fixes

- **iGPU no longer skipped when RPC peers are present** — after #23007 reclassified integrated CUDA/HIP devices, the selection logic dropped the local iGPU whenever any RPC server was added. Gating on `gpus.empty()` fixes this; critical for systems like AMD Strix Halo with 128 GiB unified memory (#23868, `1738129`).
- **Tensor parallelism: fix granularity for Qwen 3.5/3.6 + 3 GPUs** — corrects afmoe TP handling that caused incorrect splits on odd GPU counts (#23843, `8b0e0db`).

## Tools / Benchmarking

- **llama-bench: add `-fa auto` support, default `-ngl` to -1** — aligns llama-bench flags with other tools and updates README with current usage (#23714, `aa46bda`).

## Web UI

- **Custom CSS injection via server config** — operators can now theme a prebuilt binary through `--ui-config` without rebuilding; users can set it from the settings panel (#23904, `d749821`).
- **Fix linting setup** — exclude generated build dirs from prettier and eslint to prevent CI/local drift (#23910, `d38d50e`).

## CI / Build

- **Multiple CI fixes**: s390x release job corrected (`3375285`), ccache cleared in release jobs with macOS fix (`d4204b0`), iOS Xcode job updated to macos-26 (`4c4e91b`).

## Tests
