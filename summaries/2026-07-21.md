# llama.cpp daily summary -- 2026-07-21

A moderate day with 7 commits. Activity was concentrated in the web UI (4 commits) and hardware backend work for OpenCL/Adreno and Hexagon. A notable optimization landed for the DeepSeek V4 KV cache state serialization, reducing state size by writing only used rows.

## UI / Server UI

- **Sidebar bulk conversation actions + settings overhaul** (#25815, `2beefef`): Large feature adding shift-click multi-select, bulk delete with fork-cascade handling, a new radio-group component for title-generation settings, and a marquee selection hook. JS sandbox tool is now disabled by default and moved to Developer Settings.
- **Fix collapsed user bubble with markdown rendering** (#25869, `4ee6a9a`): Zeroed edge paragraph margins in `markdown-content.css` were uncompensated in the user bubble and system message wrappers, collapsing single-line bubbles into a sliver.
- **Fix Settings/Display tool call content toggle** (#25783, `43b5e63`): `showToolCallInProgress` was disconnected from the render path after the agentic content rework; now controls default expansion for all tool call block types. Renamed to `alwaysShowToolCallContent`.
- **Enable agentic flow when only JS sandbox is active** (#25865, `1521a9a`): The agentic gate did not count frontend tools, so with the JS sandbox as the sole tool source no `tools` field reached the server and the chat template lacked the tool system prompt.

## OpenCL / GPU

- **Adreno MUL_MAT broadcast + view_offs fix for multi-stream** (#25910, `178a6c4`): Two bugs in Adreno quantized MUL_MAT caused garbage output for all but the first stream in llama-server with GDN models (e.g., Qwen3.5 9B/35B). `view_offs` was dropped (every non-first sequence read slot-0 activations) and broadcast was unsupported. Both fixed; tested on Adreno X1 and X2.

## Hexagon

- **Add CLAMP op** (#25934, `76f46ad`): Adds f32 CLAMP op support to the Hexagon HTP backend.

## Core / Inference

- **llama_dsv4: write only used rows in state** (#25325, `91d2fc3`): The DSV4 KV cache previously serialized the entire cache as state. Now only used rows are written, reducing state size proportionally to cache utilization.
