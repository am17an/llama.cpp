# llama.cpp daily summary -- 2026-08-25

A busy day dominated by two large Metal backend overhauls, plus DeepSeek V4 tensor-sharding support, a correctness fix for `ggml_clamp`, and several targeted bug fixes and CI improvements across 12 commits total.

## Metal

- **Per-op source split + parallel compile** (#26561, `b615f5b4`): Splits the monolithic `ggml-metal.metal` (~12k lines) into 27 separate per-op kernel files under `kernels/`, compiled in parallel using GCD. Also adds col2im_1d, set_rows f16, depthwise convolution, Q2_0, snake activation fusion, and FWHT kernels. Large structural refactor with no functional regressions intended.
- **Per-device tuned (Q, NE) for flash-attn vec** (#26570, `f280b269`): Adds 53 new f16 (Q, NE) flash-attention vector instantiations and a per-family device tuning table dispatched at runtime. Includes a new standalone `tools/tuning/` harness for offline performance sweeps and quantized KV-cache support in FA vec. Notable new feature for Metal inference performance.

## CUDA / GPU

- **Shorten virtual device naming** (#27608, `a14dba68`): Cleans up device description strings for CUDA and Metal virtual devices; device description now built at init time.

## WebGPU

- **Fix flash-attention include ordering** (#27545, `c1c766da`): Reorders WGSL shader includes so `V` declared in `common_decls.tmpl` is not clobbered by `K` in `flash_attn_decls.tmpl` when KV_OVERLAP is set.

## Models

- **DeepSeek V4: `-sm tensor` support** (#26490, `bf0a29cc`): Adds tensor-level split-mode for DeepSeek V4 via `ggml-backend-meta`, includes model saving, delayed all-reduce for shared experts, and device-specific dflash dispatch.
- **Mamba2: flatten projections to use GEMM** (#27513, `a130532a`): Flattens in/out projections so batched inference dispatches GEMM instead of GEMV; removes a redundant reshape.

## Fixes

- **Fix `ggml_clamp`** (#27644, `6036c635`): Correctness fix for the clamp op; also updates `ggml-alloc`.
- **Fix GLM regression in `index_tensors`** (#27655, `71cc86fa`): Conversion script fix for GLM models.
- **mtmd: fix moov atom at end of file** (#27596, `160c6b0b`): Handles MP4 files where the moov atom appears after mdat; also fixes SIGPIPE on broken pipes (including Windows).
- **Read `repetition_penalty` from generation_config.json** (#27659, `b3c3b96a`): Maps the standard HF key `repetition_penalty` to `sampling_penalty_repeat` in metadata.

## Tests / CI

- **Disable DOTS3NOTE WebGPU arch test** (#27654, `75844307`): Skips the arch test for WebGPU pending support.
- **Extend ccache-clear to all CI jobs** (#27602, `985b1491`): Applies cache eviction logic to Apple, Vulkan, WebGPU, SYCL, OpenCL, OpenVINO, WASM, and server workflows; extracts logic into `scripts/ccache-clear.sh` with proper macOS/BSD date compatibility.
