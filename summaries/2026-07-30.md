# llama.cpp daily summary -- 2026-07-30

10 commits landed on upstream/master in the last 24 hours, spanning GPU backend
fixes, a notable new speculative-decoding architecture, RPC extension, and
server/conversion polish. The GLM-5.2 MTP merge is the most significant change;
the CUDA MMQ shared-memory guard is a notable crash fix for non-mainstream
hardware.

## CUDA / GPU

- **Disable MMQ when per-block shared memory < 48 KiB** -- avoids
  `GGML_ABORT` on Moore Threads MTT S70 (28 KiB) and any other device below
  the 48 KiB floor assumed by existing MMQ tile configs; falls back to the
  BLAS path transparently. (#26141, `caa596a`)
- **Separate MMQ configs for RDNA3 and RDNA3.5** -- new
  `mmq-config-rdna3.cuh` and `mmq-config-rdna3-5.cuh` so each micro-arch can
  be tuned independently of RDNA4. (#26199, `60bccc3`)

## SYCL

- **Contiguous fast path + 32-bit index math for unary elementwise ops** --
  uses fastdiv for index math; performance improvement for Intel GPU
  users. (#25946, `11b068d`)

## Model / Speculative Decoding

- **GLM-5.2 (GLM_DSA) NextN/MTP speculative decoding** -- adds `graph_mtp`
  for GLM_DSA: dense MLA attention, sigmoid-gated MoE + shared expert, shared
  head. Converter gains `--mtp`/`--no-mtp` flags. Measured ~1.37x throughput
  with greedy decoding (0.66 acceptance rate) on a 744B-A40B IQ1_S quant.
  Bumps to 5th in-tree draft-mtp implementation. (#25980, `7be2c65`)
- **Move suppress_tokens handling to common/sampling** -- refactors logits
  bias handling out of `llama-vocab` into the common sampling path for reuse;
  also addresses a security issue and removes `has_logit_bias`.
  (#26276, `afeebe1`)

## RPC

- **Add tensor_memset** -- new RPC op needed for DSV4 cache-clear-per-sequence;
  bumps the RPC major version (breaking change). (#25912, `f5b9bd3`)

## API / Server

- **Trace logging for slot similarity checking** -- adds `LLAMA_LOG_LEVEL_TRACE`
  output for prompt cache slot selection: skip reasons and similarity scores.
  Useful for diagnosing cache miss behavior. (#26271, `992c325`)

## Conversion

- **Fix Qwen2.5-Omni mmproj conversion regression** -- `convert_hf_to_gguf.py
  --mmproj` was emitting only 1 tensor (~7.7 MB) instead of ~1008 (~2.6 GB),
  breaking model loading. (#26262, `e1af89a`)

## Vendor / Misc
