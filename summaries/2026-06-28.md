# llama.cpp daily summary -- 2026-06-28

Seven commits merged to upstream/master in the last 24 hours, with GPU backend improvements dominating. The standout changes are a major OpenCL flash-attention overhaul targeting Adreno GPUs and a CUDA strided-copy fast path delivering ~7.5% throughput gains with multi-parallel-sequence setups. A binary rename constitutes a potential **breaking change** for scripts invoking `rpc-server` or `export-graph-ops` by name.

## CUDA/GPU

- **cudaMemcpy2DAsync fast path for strided ggml_cpy** (#25057, `0ed235ea`) -- Avoids the slow scalar copy kernel when rows are contiguous but tensors are not fully contiguous; uses `cudaMemcpy2DAsync` instead. Fixes GDN recurrent snapshot with `-np 4`, nets ~7.5% tok/s improvement on RTX 5090 + Qwen3-27B Q4_K_M at `-np 4`. OpenVINO backend returns "unsupported" for this path; new tests added.

## OpenCL

- **Flash-attention overhaul for Adreno GPUs** (#25069, `ebd048fc`) -- Full rework of the FA kernel for f16/f32 with prefill prepass kernels (pad KV/mask tiles, classify fully-masked vs. mixed KV tiles to skip masked work), new q4_0/q8_0 quantized KV-cache kernels, dequant kernels, and a tile-tuning table with override support. Targets Android flagships and Windows-on-Snapdragon (X1/X2). AI used for prototyping, manually reviewed.

## Vulkan

- **Fix step operator for 0 input** (#25036, `0b6529d8`) -- Corrects an edge case in the Vulkan step operator when input is zero.

## SYCL

- **Fix failing norm unit tests** (#25044, `9bebfcb4`) -- Resolves SYCL norm UT failures.

## Build / Binaries (breaking change)

- **Rename rpc-server and export-graph-ops** (#25045, `c299a92c`) -- `rpc-server` -> `ggml-rpc-server`; `export-graph-ops` -> `ggml-export-graph-ops`. Motivated by namespace collisions in `/usr/bin`. Any scripts or docs using the old names must be updated.
