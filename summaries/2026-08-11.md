# llama.cpp daily summary -- 2026-08-11

An active day with 23 commits: two notable new model architectures landed, a large multi-output backend sampling feature merged, OpenCL and WebGPU performance work, CI upgrades for ROCm 7.14 and CUDA 13.4, and several bug fixes spanning Android CPU affinity, MoE model saving, and ROLL contiguity checks on CUDA/Metal.

## Inference / Sampling

- **Multi-output backend sampling** (GPU-side sampling with token speculation) merged after a long review cycle -- significant feature enabling speculative decoding with backend-side sampling across CUDA/Vulkan/Metal; adds `n_seq_max_outputs` context parameter (#25532, `dd1ea52`); follow-up API cleanup (#26852, `030ebb5`)

## CUDA / OpenCL / Metal / WebGPU

- **OpenCL FA prefill**: transpose K tile in local memory for flash attention prefill kernels, improving performance (#26428, `689e227`)
- **WebGPU**: refactor several WGSL files and simplify flash_attn shaders, reducing code size significantly (#26134, `f401bb1`)
- **ROLL op**: require contiguous src on CUDA and Metal -- previously a permuted tensor would silently produce wrong results; both backends now reject non-contiguous inputs (#25928, `f8def7f`)

## API / Server

- **Docker test gating**: gate tools runtime tests on an actual container run rather than `docker info`, fixing false-pass on Windows CI (#26826, `1e396e7`)
