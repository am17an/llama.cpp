# llama.cpp daily summary -- 2026-08-01

Heavy GPU-backend day with 16 commits merged. The most significant landing is an oneMKL GEMM flash attention implementation for Intel XMX hardware on SYCL, delivering roughly 2x prompt-processing throughput on Battlemage GPUs. Vulkan also gained a new POOL_1D op and a stability fix for Windows Intel drivers.

## SYCL

- Add oneMKL GEMM flash attention for XMX-accelerated prompt processing -- ~1.97x speedup on Battlemage at 32K context; covers F16/BF16/quant KV caches with safe gate guards (#25025, `9d9a6d2`)
- Support missed types in `cpy` op (#26005, `d5d3e05`)
- Support Q2_0 `mul_mat` (#26231, `a2be61d`)
- Fuse RMS_NORM + MUL into a single kernel for lower dispatch overhead (#26015, `1553725`)
- Support device-to-device memcpy via `DEV2DEV_MEMCPY_FORWARD` (#26234, `1c5b89f`)

## Vulkan

- Update Vulkan SDK to 1.4.357.0 in CI (#26303, `6f3c0a7`)

## CUDA

## WebGPU
