# llama.cpp daily summary -- 2026-08-06

A busy day with 14 commits merged to master, spanning multimodal (mtmd) improvements, server hardening, grammar fixes, build cleanup, and UI updates. The most substantial changes are a correctness fix for the ggml compute graph ordering in audio/vision models, a major overhaul of the server file-search path on Windows, and expanded multimodal batching for DeepSeek-OCR.

## mtmd / Multimodal

- **`ggml_build_forward_order` added** to fix a bug where audio-graph GEN_WAV calls executed the wrong branch with stale inputs, causing a bound assertion on CPU; the fix avoids forcing the compute flag on ordering hints -- #26649 (c8e03ce)
- **DeepSeek-OCR multi-row batching** now weaves all rows in a single pass instead of per-row, improving throughput -- #26154 (717dad5)
- **Unlimited-OCR max_tiles fix** corrects the tile limit and converter setting for DeepSeek-OCR -- #25614 (b06aa77)

## Server / API
