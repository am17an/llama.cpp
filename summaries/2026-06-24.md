# llama.cpp daily summary -- 2026-06-24

Today saw 12 commits merged to upstream master, with heavy activity in the Vulkan backend (5 PRs
from a single contributor) and meaningful server-side improvements including smarter checkpoint
creation. A new model family (Granite Speech Plus) landed, and the WebGPU backend gained a notable
speculative-decoding perf boost.

## Vulkan

- Expanded backend op coverage: SQR, SQRT, SIN, COS, CLAMP, LEAKY\_RELU, and NORM now support all
  backend tests, including noncontiguous inputs (#24582, `72a9269`)
- Added GET\_ROWS\_BACK support (#24883, `92e854a`)
- Added CONV\_3D support via a port of conv2d\_mm.comp (#24612, `c560636`)
- Made mul\_mm ALIGNED a specialization constant, trimming shader variant count and reducing binary
  size (#24689, `0eb874d`)
- Fixed link failure for debug builds with GGML\_VULKAN\_CHECK\_RESULTS / RUN\_TESTS enabled -- ggml-cpu
  was missing from the link after the CPU backend split (#24444, `c926ad0`)

## WebGPU

- Dramatically improved MTP (multi-token prediction) speculative decoding speed by routing small
  batches through the mat-vec path; measured 2-3.5x speedup on Qwen3.5 and Qwen3.6 27B on M2 Pro
  (#24811, `7c908502`) -- **notable perf gain**
- Added yomaytk as CODEOWNERS for ggml-webgpu (#24930, `035cd8f`)

## OpenCL

- Improved q8\_0 GEMV precision for sensitive models (#24923, `23ee879`)

## API / Server

- Improved user message boundary detection in server token spans and added checkpoints before every
  user message (previously only at the last); min-step raised to 8192 (#24176, `73618f2`)
- Fixed remote preset handling and added a CI test for it (#24938, `75ad0b2`)
- Added error checking on draft context creation failure (#24922, `be4a6a6`)

## Models

- Added Granite Speech Plus: extends the existing granite\_speech model with multi-layer audio
  feature concatenation for the IBM GraniteSpeechPlus architecture (#24818, `a3900a6`)
