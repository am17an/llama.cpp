# llama.cpp daily summary -- 2026-06-21

Today saw 10 commits land on upstream/master, covering a notable CPU performance win, a security fix in the server's CORS proxy, model loading improvements for GLM-5.2, and a handful of build/conversion/test fixes. No breaking changes are evident.

## Performance

- **ggml/AMX**: Flatten thread partition over `n_batch * M` so all cores participate in quantization; up to 1.47x speedup on pp512 for Q4_K_S / Q4_K_M on Intel Xeon Platinum 8488C. (#24806, `37a77fb`)

## Security / API / Server

- **server**: Stop forwarding `Authorization` (and other auth) headers through the CORS proxy endpoint, preventing credential leakage to third-party MCP servers. Includes new unit and e2e tests. (#24373, `e27f308`)

## Model Support

- **GLM-DSA (GLM-5.2)**: Mark the five DSA lightning-indexer tensors as `TENSOR_NOT_REQUIRED` so layers that omit them (GLM-5.2 partial indexer) load as `nullptr`; GLM-5.2 GGUFs were previously broken at load time. DeepSeek-V3.2 is unaffected. (#24770, `796f41b`)

## Fixes

- **hexagon**: Use padded stride for ssm-conv weights in the HTP backend, fixing a correctness bug. (#24470, `4a80943`)
- **arg / Windows**: Guard the Win32 UTF-8 argv override so it only fires when `argc` matches, fixing a flaky `test-args-parser` failure in the OpenVINO Windows CI workflow. (#24826, `75f460a`)
- **llama-quant**: Swap raw string literals for `LLM_KV` macros in `quantization_version` and `file_type` metadata writes. (#24802, `84de01a`)

## Conversion

- **convert**: Consolidate `rope_parameters` handling across 15 model conversion scripts (`bailingmoe`, `chatglm`, `deci`, `exaone`, `gemma`, `glm`, `llama`, `mimo`, `minicpm`, `nemotron`, `phi`, `qwen`, `stablelm`, `step3`, `base.py`). (#24833, `f4043fe`)
- **json-schema-to-grammar**: Align trailing-space rules between the C++ grammar generator and the PEG parsers (follow-up to #24624). (#24835, `c576070`)

## Build / DevOps

- **docker/s390x**: Pre-build the web UI in CI before the s390x Docker build to work around missing `lightningcss` binaries for that architecture. (#24829, `67e9fd3`)
- **release**: Add missing download link for the Windows OpenCL Adreno arm64 artifact. (#24809, `8452824`)
