# llama.cpp daily summary -- 2026-07-12

A busy day dominated by DeepSeek V3.2/V4 improvements and Qualcomm Adreno GPU optimizations across three backends (OpenCL, Vulkan, CUDA). The headline change is a major new fused GGML op for the DeepSeek lightning indexer that cuts CPU compute buffer size from ~168 GiB down to ~5.8 GiB.

## DeepSeek / Model

- **New `GGML_OP_LIGHTNING_INDEXER` op** fuses DeepSeek V3.2/V4 lightning indexer computation, reducing compute buffer memory by ~29x on CPU; bumps RPC version; wired into `deepseek32.cpp` and `deepseek4.cpp` -- #24231, `00f5442`
- **DeepSeek V4 KV cache amnesia fix**: `clear()` now targets only the relevant sequence rather than wiping the full cache, resolving multi-turn memory loss (#25171) -- #25521, `13f2b28`

## OpenCL / Adreno

- **int8 DP4A dense + MoE prefill optimization for Adreno** (X2-90): adds dp4a GEMM kernels for q4_0, q4_K, q5_K, q6_K, q8_0, IQ4_NL, mxfp4 and MoE variants; reports +55-70% pp throughput on Qwen3-30B -- #25537, `1d1d9a9`

## Vulkan / Adreno

- **Route large matmuls to medium tile on Adreno**: prevents crashes/hangs on long prompts with q4_0 models by avoiding the large tile shader that exceeds Adreno shared memory limits at runtime -- #24877, `76f2798`

## CUDA

- **Don't crash on `cudaMemGetInfo` when device has no free memory**: makes the OOM error non-fatal, assigns zero total/free memory so the fit algorithm skips the device; also fixes `-dev none` crash -- #25157, `3cec3bc`

## API / Server

- **Streaming support for `exec_shell_command`**: `"stream": true` now works for the built-in shell tool; adds tests and updated dev docs -- #25526, `c92e806`
- **Refactor `server_stream`**: removes non-thread-safe `rd.stop()` call, makes spipe logic self-contained in `server_res_spipe`, reduces overall code size -- #25541, `ea1f7bb`

## Fixes / Misc

- **Fix split-mode error message condition** in `llama-model.cpp`: corrects a stale conditional so the `LLAMA_SPLIT_MODE_TENSOR not implemented` warning displays correctly -- #24926, `e3546c7`
- **Reject empty GGUF metadata keys**: `gguf.cpp` now returns an error on empty-string keys, with a new test -- #24917, `d72bfa3`
