# llama.cpp daily summary -- 2026-08-29

A busy day with 15 commits spanning Metal performance tuning, a notable Vulkan correctness fix, a large OpenVINO backend update, SYCL improvements, and an expanded test suite that also shook out several latent bugs.

## Metal

- Added fa-vec tuning tables for M4 (#27875, `f5e85d4`), M4 Pro (#27824, `6d6b697`), M3 Max, M5 and M5 Pro (#27863, `8963a9b`) -- community-contributed sweeps to improve flash-attention performance on newer Apple silicon.
- Disabled non-fused GDN and LID ops in context scheduler (#27877, `8663224`) -- forces fused Lightning Indexer/GDN path; avoids silent CPU fallback for affected model archs.

## Vulkan / GPU

- **Bug fix (correctness):** Fixed missing view-alias dependencies in `ggml_vk_graph_optimize` (#27812, `b387ddf`). The optimizer was reordering nodes across aliased reads/writes, producing silently wrong tokens under greedy decoding on models with view-aliased state (e.g. Qwen3.8 recurrent layers) on AMD and NVIDIA Vulkan. CUDA was not affected.
- Added hoisting support for row IDs and expert count in Vulkan shaders (#26686, `90c26fc`).

## SYCL

- Route quantized KV decode to TILE kernel on Xe2/BMG only; keep VEC on other archs (#26689, `d077b4c`).
- Bind f16 KV cache in-place for oneDNN SDPA path (#27468, `be87620`) -- eliminates ~285 MB per-ubatch staging traffic at large KV lengths.

## OpenVINO

- Major backend update to OV 2026.3.1: adds whisper.cpp support, Qwen3.5 on NPU, several new ops, and a conv-fusion pass (#27843, `511f9c1`). Large diff (+1121/-266 lines).

## Models / GGML

- Reduce graph splits for qwen4exp (#27880, `6fe7498`) -- performance improvement.
- Fixed `conv_transpose_2d` for multiple batches on CPU and Metal (#26132, `a43c398`) -- only batch 0 was computed previously; multi-batch results were silently zero.

## Tests

- Extended `test-save-load-state` to run across all model architectures (#27755, `4e97ac8`). In the process, fixed: on-device seq-copy chunking mismatch (gemma2/gpt-oss/lfm2), dangling hparams ref in minimax-01 LA graph input (use-after-free on graph reuse), and dsv4 n_stream save/load mismatch.

## Tools / Build

- `llama-bench`: added `--tensor-read-lazy` flag (#27881, `50f068f`).
- Convert: prevent ndarray conversion in `LazyChunkedTensor` to avoid memory spikes (#27869, `b19cbe9`).
- Snapdragon: ported SDK setup to Python script for Windows (#27903, `d7bd3bf`).
