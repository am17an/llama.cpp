# llama.cpp daily summary -- 2026-07-31

Active day with 17 commits landed on upstream/master, spanning GPU backends (CUDA, Vulkan, Metal), model support (mimo2, MiniMax M3), server API, multimodal tooling, and a significant README restructuring. The ggml library was bumped to version 0.18.0.

## CUDA/GPU

- **CUDA: add Q2_0 quantization support** -- new quant type backed across mmq, mmvq, dequant, getrows, and convert paths; requires new tile-load CUH and template instance (#25707, 9b2a088)
- **ggml-cuda: transpose-free gemmv for 1xK weights** -- avoids redundant transpose when weight matrix shape is 1xK, improving matmul-vec throughput (#26171, e1a1abb)
- **Vulkan: quantized concat support** -- extends concat op to handle quantized tensor types in the Vulkan backend (#25684, ea63b4d)
- **Test: alternative conv layout (cwhn)** -- adds cwhn=true/false test cases and backend-level support checks across CPU, CUDA, and Vulkan (#25617, 958d9c0)

## Metal
