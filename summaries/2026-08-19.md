# llama.cpp daily summary -- 2026-08-19

19 commits merged to upstream/master in the last 24 hours. Activity was broad: two significant performance improvements (CUDA/SYCL GPU kernels), a UI services/stores overhaul, a KV-cache-breaking unicode bug fix, and several CI/build improvements. No breaking API changes were identified.

## CUDA/GPU

- **CUDA MMVQ nwarps=8 for bs=1 on DGX Spark (GB10)**: tunes MMVQ kernel warp count for dense models on NVIDIA GB10 hardware; skips MoE experts and small K geometries. (#26843, `25ae3a9b`)
- **SYCL FWHT kernel**: ports `ggml_hint_src0_is_hadamard` fast Walsh-Hadamard transform from CUDA to SYCL, yielding 3.3x-6x speedup for eligible ops. (#27298, `0882c7bc`)

## OpenCL

- **Fix WAR race in flash-attention tile kernels**: resolves a write-after-read race when a work group spans multiple subgroups in the generic FA kernels. (#26434, `60addddf`)

## RPC

- **Populate use_count for op fusion**: RPC backend now fills `use_count` on tensors, enabling operation fusion inside remote backends; bumps minor version. (#27142, `af517262`)

## Multimodal (mtmd)

- **DeepSeek-OCR SAM conv2d fix**: keeps `im2col` in F32 for `ggml_conv_2d` in the SAM path, fixing numerical accuracy. (#26727, `9731ad3f`)
- **Fix LFM2 image tiling threshold**: corrects off-by-one in tiling logic for LFM2 models; adds unit tests. (#27057, `7acdbb1f`)

## Unicode / tokenization

- **Add '~' to collapsed symbol class**: `\p{S}` was missing `~`, which split ` ~` into two pre-tokens and broke the `G~` BPE merge used by DeepSeek V4 -- causing re-tokenized prompts to diverge and killing KV cache reuse. Notable correctness fix. (#26972, `afd439df`)

## UI

- **Services consolidation refactor**: moves stream lookup, model SSE feed, and conversation import/export out of stores into dedicated service classes; adds explicit `initStores()` to fix migration-vs-load races. (~600 lines changed, #27239, `3dc7285b`)
- **Stores consolidation refactor**: merges device/theme/viewport into one `deviceStore`, merges build info into version store, removes dead code. (#27238, `fdf4c646`)

## Server

## Common / quantization

- **Evict weights after each quantization layer**: frees mmapped weight pages after the layer is processed, reducing peak memory during quantization. (#22877, `05967042`)
