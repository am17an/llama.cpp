# llama.cpp daily summary -- 2026-07-06

All 5 commits merged today targeted CUDA/GPU correctness, with a tight focus on multi-GPU tensor-parallel
configurations and quantized-type support. No API-breaking changes; all fixes are additive or narrow in scope.

## CUDA/GPU

- **concat for quantized types**: Added CUDA `GGML_OP_CONCAT` support for quantized tensors by reusing the
  existing uint8 kernel (passing `nb[1]` instead of `ne[0]`). Required for DeepSeek V4 quantized KV cache
  to avoid CPU fallback. PR #25303, `78d2f52`
- **VMM pool P2P access fix (Turing)**: Fixed OOB writes in NCCL allreduce staging buffers on Turing
  multi-GPU NVLink setups by granting peer device access in VMM pool allocations. Adds a fallback code path
  when NCCL/P2P is unavailable. PR #24491, `7a63fde`
- **tensor-parallel + MoE crash fix**: Resolved `GGML_ASSERT(ggml_is_contiguous)` abort when combining
  `-sm tensor` with `-ncmoe` (CPU-offloaded MoE experts). The assert fired on mirrored non-contiguous
  router tensors before the split-state lookup; fix moves the lookup above the assert. PR #25028, `4b2a0cd`
- **multi-buffer safety abort**: Meta backend now aborts explicitly (instead of segfaulting silently)
  when it encounters a multi-buffer, pending a proper fix in issue #22197. PR #25276, `3e5036f`

## Fixes

- **stale tensor-split params for draft models**: Tensor-split parameters went out of scope when creating
  Eagle3/DFlash speculative draft models, causing exceptions under `-sm tensor` with Qwen models. Fixed
  by backing up params inside the model struct. PR #24814, `2da6686`
