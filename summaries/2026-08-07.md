# llama.cpp daily summary -- 2026-08-07

Eight commits landed on upstream/master in the last 24 hours, spanning CI infrastructure, Vulkan debugging, multimodal chunk serialization, and a handful of conversion/loader fixes. The ROCm CI onboarding is the largest change and the most operationally significant; everything else is targeted bug fixing or minor ergonomics.

## CI / Build

- **AMD ROCm CI onboarded for gfx1151 (Strix Halo)** -- adds a new self-hosted `gpu-rocm` job and three accompanying workarounds: a debug-assert fix for integrated-GPU host output buffers in CUDA, `HIP_LAUNCH_BLOCKING=1` to fix async-correctness issues on RDNA3.5, and jamba skipped on HIP pending an SSM-kernel accuracy investigation. (#26544, a1f96d4)

## Vulkan

- **Fix submission batching threshold and add DeviceLost debug tooling** -- the batching loop previously only stopped *after* exceeding the FLOP limit, making submissions larger than intended; the threshold is now applied before adding a tensor. Adds `GGML_VK_SERIALIZE_SUBMISSIONS` env var and `VK_EXT_device_fault` support to help diagnose driver crashes. Notable for AMD Linux users seeing DeviceLost errors. (#26371, 803b7fc)

## Multimodal (mtmd)

- **Add chunk save/load API** -- new `mtmd_input_chunk` serialize/deserialize functions with C-API coverage and tests, enabling callers to cache pre-processed multimodal inputs. (#26645, 15586e2)

## API / Server

- **Fix empty response from `/cors-proxy`** -- corrects a regression where the CORS proxy endpoint returned an empty body. (#26656, 6a32c29)

## Model Loader / Core

- **Fix quantized reshaped tensor strides** -- stride construction did not account for quantized element sizes, causing incorrect strides for reshaped quantized tensors. (#26672, 3db4ff8)

## Conversion

- **Fix DeepseekV4 YaRN rope parameters with transformers 5.x** -- `transformers` 5.x uses a new `rope_parameters` layout; the converter now reads from it so YaRN params are not silently dropped. (#26673, eb5667a)
- **Accept `ExaoneMoeForCausalLM` arch spelling** -- LG AI Research renamed the arch (capital E -> lowercase e) when merging into Transformers v5; both spellings are now registered. (#26660, e700bfb)
- **Add `--model-name` to conversion scripts** -- lets callers override the `general.name` metadata field in causal and embedding conversion scripts. (#26665, 9de0fcf)
