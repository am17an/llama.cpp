# llama.cpp daily summary — 2026-07-11

An active day with 18 commits: the headline is the initial landing of the ExecuTorch (ET) backend — a massive new inference backend — alongside DeepSeek V4 attention improvements, Hexagon perf work, and several server/UI polishes.

## New Backend

- **ggml-et: Initial ExecuTorch (ET) backend** — adds a full new GGML backend targeting ExecuTorch with support for matmul (Q4_0, Q8_0, f16, f32), flash attention, RoPE, RMS norm, softmax, ROPE, SSM ops (Mamba/RWKV), GLU, and more; includes custom kernels for matrix-engine acceleration and a CMake build system. (~86 files, 40k+ lines added) PR #24179 `082b326`

## Inference / Attention

- **DeepSeek V4: make all KQ masks f16 when FA is used, remove zero attention bias, remove raw_k repeats** — cleans up and potentially changes attention behavior for DeepSeek V4 models; removes redundant work in the attention graph. PR #25370 `2ed3c1a`
- **llama: fix perf regression — make tensor-split regex patterns static** — `llama_meta_device_get_split_state()` was recompiling 29 `std::regex` objects on every call (once per tensor per token in split mode); marking them `static const` eliminates that overhead. PR #24710 `c749cb0`

## Hexagon / Mobile
