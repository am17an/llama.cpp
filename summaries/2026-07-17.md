# llama.cpp daily summary -- 2026-07-17

A heavy GPU/backend day with 21 commits merged. The biggest items are fused hyper-connection ops for DeepSeek V4, CUDA Virtual Device support, and a notable CUDA MoE activation-quantization deduplication that delivers ~3-6% prefill speedup on MoE models. Multiple OpenCL/Adreno fixes landed as well.

## CUDA / GPU

- **DeepSeek V4: fused hyper-connection ops** -- adds new ggml ops (`GGML_OP_DSV4_HC_*`) with CPU and CUDA backends; also adds RPC version bump and test coverage. Notable new feature. (#25585, `0dc74e3`)
- **CUDA Virtual Devices** -- support for splitting a single physical GPU into virtual devices; disables NCCL path for virtual devices; adds GPUx2 CI jobs. (#25228, `79bba02`)
- **CUDA: MoE activation quant dedup** -- each token's activation is quantized once instead of once-per-expert; fused quantize+scatter kernel for NVFP4 yields ~61% reduction in activation-quant GPU time; bit-identical output. ~3-6% prefill gain on RTX 5090 for Qwen3/Gemma MoE models. (#25441, `5839ba3`)
- **CUDA graphs on Volta+Turing** -- previously restricted to Ampere+; one-line guard relaxed. (#25749, `3f08ef2`)
- **HIP: restore `prop.integrated`** -- PR #16308 had unconditionally forced `integrated=false` as a Jetson workaround; now guards it to CUDA-only, restoring correct behavior on AMD APU/UMA under ROCm. Fixes #23977. (#24233, `c7d8722`)
- **CUDA Q1_0 extraction via `__byte_perm`** -- micro-optimization for Q1_0 dequant in MMQ/vecdot. (#25628, `602f828`)
