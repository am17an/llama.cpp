# llama.cpp daily summary -- 2026-07-29

Active day with 17 commits merged to upstream/master, spanning GPU backends (CUDA, Metal, Vulkan, WebGPU, OpenCL, SYCL), two new speculative decoding methods, two new model integrations, and a server refactor. The OpenCL Adreno multi-stream bug fix is a notable correctness regression fix worth attention if you run multi-sequence workloads on Qualcomm hardware.

## CUDA/GPU

- **ggml-cuda**: Chunked SSD matmul for Mamba-2 prefill acceleration -- significant throughput gain for Mamba-2 models on CUDA (#22675, `b62b350`)
- **Vulkan**: Restore iq4_nl support in flash attention (#24585, `8161641`)

## Metal

- **ggml-metal**: New FWHT (Fast Walsh-Hadamard Transform) kernel (#25924, `f95de97`)

## WebGPU

- **ggml-webgpu**: Fix binding alias issues to support all architectures; also fixes recurrent-state-rollback test, handles >4 GB buffer offsets and view offsets (#25931, `bc71c24`)

## OpenCL

- **opencl**: Fix Adreno KQ/KQV image kernels silently producing garbage on multi-sequence batches (ne03/ne13 > 1) -- e.g. llama-perplexity with default settings or multi-slot server on Adreno 740. PPL dropped from ~1817 to ~15.6. (#26189, `8190848`)

## SYCL

- **sycl**: Fix use-after-return of SDPA scale in oneDNN flash-attention path; replaces a racy static unordered_map with a single_task write, closing both the data race and a leaked device allocation (#25880, `d6b61ac`)
