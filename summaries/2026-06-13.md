# llama.cpp daily summary -- 2026-06-13

A busy day with two standout features landing: full EAGLE3 speculative decoding support and a batching API for the multimodal (mtmd) subsystem. GPU backend work continued across Vulkan, CUDA, SYCL, and OpenCL, while CI received several stability fixes to unblock the release pipeline.

## Speculative Decoding

- **EAGLE3 speculative decoding support** (#18039, `88a3927`) -- Major addition (~1161 lines). Adds a new `eagle3.cpp` model and wires EAGLE3 into the speculative sampling path, including conversion support in `convert_hf_to_gguf.py` and `gguf-py`.

## Multimodal (mtmd)

- **Batching API for mtmd** (#24384, `e37abd6`) -- Adds `mtmd_batch` API enabling parallel image/audio processing in a single forward pass; wires up `support_batch()` per vision encoder and threads it through the server context.

## OpenCL / Mobile GPU

- **q5_0/q5_1 GEMM and GEMV kernels for Adreno** (#24319, `ba1df05`) -- Adds ~1642 lines of OpenCL kernels for Qualcomm Adreno GPUs, extending quantized inference coverage to 5-bit types.

## Vulkan

- **Pipeline barriers for memcpy read operations** (#23770, `3e7bd4f`) -- Adds missing Vulkan memory barriers before memcpy reads, fixing potential data-hazard race conditions.

## CUDA / ggml

- **concat op for scalar types on CUDA backend** (#24011, `85f99dc`) -- Extends `concat.cu` to handle scalar (non-vector) types; includes a Metal device-side fix as a side effect.

## API / Server

- **Fix reasoning budget WebUI precedence over model.ini** (#24517, `ebc1077`) -- Per-request `thinking_budget_tokens` from the WebUI was being silently overridden by `model.ini`; now WebUI value takes precedence with `model.ini` as fallback.

## UI

- **PWA support** (#23871, `f7ca93d`) -- Server WebUI can now be installed as a Progressive Web App.
- **JPEG EXIF orientation** (#24196, `6471e3c`) -- Corrects image display for photos with non-default EXIF rotation metadata.

## SYCL / CI

- **Fix SYCL CI build and release** (#24387, `099ea76`) -- Restores SYCL build pipeline with ccache, Windows processor-count fix, and deduplication of CI steps.
- **Fix SYCL links in release notes** (#24527, `c34b922`) -- Corrects broken SYCL documentation URLs in the release workflow.
- **Unbreak release pipeline** (#24544/`cd50446`, #24545/`f58bad4`) -- Two follow-up fixes to stabilize the automated release action after the SYCL CI overhaul.

## Build / Dependencies

- **Avoid including llama-ext.h in fit.h** (#24506, `02182fc`) -- Reduces header coupling; `fit.h` no longer transitively pulls in internal model headers.
- **Update cpp-httplib to 0.47.0** (#24395, `70b54e1`) -- Vendor bump for the HTTP library used by the server.

## Misc

- **ggml sync + version bump to 0.15.1** (`f532be8`, `e08c226`) -- Routine upstream ggml sync and library version increment.
