# llama.cpp daily summary -- 2026-06-17

Today's 12 commits were dominated by GPU backend improvements across Vulkan and SYCL, with notable work on speculative decoding metrics and a UI enhancement for the web interface. No breaking changes were identified, but SYCL on Intel hardware now defaults to F16 mode.

## CUDA/GPU

- **NVFP4 edge-case fixes in llama-graph**: Fix and restrict NVFP4 graph build for lora/bias-add ordering and unsupported FFN combinations -- #24331 `02810c7`

## Vulkan

- **UMA host-visible memory buffers**: Prefer host-visible buffers on unified memory devices to reduce unnecessary copies -- #22930 `32120c1`
- **gated_delta_net S_v=16 support**: Extend Vulkan backend to handle gated_delta_net with S_v=16 -- #24581 `d5fb104`
- **col2im_1d op**: Add `GGML_OP_COL2IM_1D` GPU kernel with bounded gather loop -- #24425 `ad39cca`

## SYCL

- **MoE MUL_MAT_ID reordered quants**: Support reordered Q4_K, Q5_K, Q6_K for fused MoE mul_mat_id; unsupported 3D cases now fall back instead of aborting -- #24452 `ac79caa`
- **New ops: EXPM1, FLOOR, TRUNC, ROUND**: Full unit test coverage for these element-wise ops on SYCL -- #24363 `fdd1098`
- **GGML_SYCL_F16=ON now default**: F16 mode is now the default for SYCL builds; Dockerfile and example scripts retain explicit F16 flags -- #23996 `4196b47` *(behavior change)*

## Speculative Decoding

- **Eagle3 backend sampling**: Add draft-model backend sampling support for Eagle3 speculative decoding -- #24655 `a182490`
- **Acceptance metrics**: Expose mean acceptance length and per-position acceptance rate in spec decode stats -- #24536 `635b65a`

## API/Server & Bench

- **bench --offline flag**: Add `--offline` flag to llama-bench and the Python bench wrapper to skip network calls -- #24511 `e3a74b2`

## UI

- **Mermaid/SVG source toggle**: Add a toggle button in the web UI to switch rendered mermaid/svg blocks to their raw source and back; tall diagrams now scroll properly -- #24652 `c1304d7`

## Build/Vendor
