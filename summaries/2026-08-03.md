# llama.cpp daily summary -- 2026-08-03

A busy day dominated by DeepSeek V4 (DSv4) infrastructure work, with significant Metal backend additions and backend-specific fixes across OpenCL, SYCL, and WebGPU. The biggest commit lands full MTP + DSpark speculative decoding support for DeepSeek V4, reporting ~60% speedup on a DGX Spark.

## DeepSeek V4 / Speculative Decoding

- **DeepseekV4 MTP + DSpark** (#25784, `596a579`): Major addition -- MTP (multi-token prediction) and DSpark speculative decoding for DSv4. Rewrites KV cache, graph, and model layers; adds `dflash.cpp`. ~50% speedup with MTP alone, higher with DSpark sidecar.
- **Metal: implement DeepSeek V4 hyper-connections** (#26459, `fffbcbd`): Implements `GGML_OP_DSV4_HC_COMB/PRE/POST` ops in Metal with SIMDgroup-optimized kernels. Large addition (~400 lines of new Metal shader and dispatch code).
- **convert: add option to create separate dspark GGUF** (#26452, `3581ba0`): New `--no-nextn` flag and split-GGUF conversion path for DSpark sidecar files.
- **common: support DSpark sidecar resolution** (#26458, `bb4e0e1`): DSpark sidecar files now resolve via the same `-hfd`/`-md` tag logic as other speculative sidecars; DSpark auto-ranks above DFlash.

## Metal

- **Metal: add F16 support for bin ops** (#26465, `9d21b57`): Enables F16 binary ops (needed for DSv4 F16 CSA mask).
- **Metal: add SILU_BACK** (#25982, `221f0f6`): Implements the SILU backward op for f32, matching existing CPU/CUDA/Vulkan coverage.

## OpenCL

- **opencl: limit local workgroup size for GLU** (#26383, `0ab9d6f`): Fixes `CL_INVALID_WORK_GROUP_SIZE` on devices with `max_workgroup_size=256` (e.g. Intel UHD 620).
- **opencl: fix missing ref_count increment in init** (#26162, `c745be2`): One-line bugfix; without this, profiling data is never flushed at program exit.

## SYCL

- **sycl: fix iGPU classification** (#26105, `272700b`): Uses Level Zero device flags to correctly identify integrated GPUs; prevents seg faults when iGPU and dGPU coexist.

## WebGPU

- **ggml-webgpu: add F16 repeat support** (#26307, `7a2db1a`): Fixes a crash on minimax-m3 caused by the WebGPU backend lacking F16 repeat, which caused a misrouted inplace ADD to run on CPU.

## Chat / Inference

- **chat: add Qwen3 specialized parser** (#26252, `f5919bf`): New PEG-based parser for Qwen3 tool-call format; adds argument permutation support and handles `<tool_call>` omission in older checkpoints.
- **model: load MiMo V2 MTP tensors only if used** (#26412, `75587a0`): Avoids loading MTP tensors for MiMo V2 when they are not needed.
