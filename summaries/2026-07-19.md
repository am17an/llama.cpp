# llama.cpp daily summary — 2026-07-19

Two focused bug-fix/correctness commits landed today. One addresses a quantization crash for DeepSeek-V4 models and the other fixes a correctness issue in the DFlash attention backend when K/V cache injection is used alongside K/V quantization.

## Fixes

- **llama-quant**: Exclude `ffn_gate_tid2eid` i32 routing table tensor from quantization — this token-id→expert-id index (used in DeepSeek-V4's MoE routing) was incorrectly being quantized, causing a crash since i32 cannot be cast to float. Fixes upstream issue #25754. (PR #25787 · `4937ca8`)

## Model / Attention

- **DFlash**: Apply K/V cache rotation when injecting K/V cache with K/V quantization enabled — without this fix, the rotary positional encoding was not applied to injected keys, leading to incorrect attention results. (PR #25823 · `571d0d5`)
