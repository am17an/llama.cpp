# llama.cpp daily summary -- 2026-06-07

Today's activity (8 commits) was dominated by multimodal (mtmd) improvements and chat/reasoning
fixes, with lighter cleanup work rounding out the day. No breaking changes identified, though the
`*/input_tokens` server API addition is a notable new surface.

## Multimodal (mtmd / server)

- **Frame merge for Qwen-VL-based models**: adds "frame merge" logic so Qwen3.5-VL and similar
  models can process video frames efficiently; includes clip-level changes and a new `merge_frames`
  flag. (#21858, `31e8249`)
- **Placeholder bitmap + `/input_tokens` API**: allows token counting without running full
  preprocessing; adds new `POST */input_tokens` endpoint to the server, with docs and proxy support.
  Large change touching 26 files. (#23913, `f5c6ae1`)

## Chat / Reasoning

- **LFM2/LFM2.5 `<think>` leak fix**: corrects reasoning round-trip serialization so `<think>` tags
  don't bleed into non-reasoning turns; gates fix by reasoning format and template capability; adds
  new LFM2.5-8B-A1B Jinja template and 300+ lines of updated tests. (#24234, `98d5e8b`)

## Vulkan / GPU

- **coopmat2 feature check**: Vulkan backend now queries `VkPhysicalDeviceCooperativeMatrix2FeaturesNV`
  before advertising coopmat2 support, preventing false positives on hardware that lacks it.
  (#24186, `5a69c97`)

## Fixes

  log output. (#24213, `588f0dc`)

## Cleanup / Refactor
