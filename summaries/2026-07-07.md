# llama.cpp daily summary -- 2026-07-07

A busy day across all backends: 14 commits landed, with a notable breaking CUDA
refactor removing the `-sm row` multiplier mode, continued IBM Power/AIX platform
improvements, and bug fixes in the server and Vulkan backends.

## CUDA/GPU

- **CUDA: remove `-sm row`, refactor cuBLAS** (#24216, `74976e1`) -- Major cleanup
  removing the `-sm row` split-k row multiply path and significantly refactoring
  cuBLAS dispatch (~1000 lines removed). Users relying on the `-sm row` flag will
  need to update. CDNA + BF16 edge cases also fixed.
- **CUDA: extend K-type validation to V-types for flash attention** (#24403, `cb295bf`)
  -- Aligns V-type checks with K-type checks in the FA dispatch path; prevents silent
  type mismatches.
- **ggml-cuda: optimize conv_transpose_1d indexing** (#25310, `72874f5`) -- Index
  arithmetic refactor for the conv_transpose_1d CUDA kernel.
- **ggml-hip: enable `-ffast-math` for HIP builds** (#23862, `d06ddd3`) -- Mirrors the
  `-use_fast_math` flag already used in CUDA. Benchmarks show 3-7% prompt-speed gains
  on RDNA3.5.

## Metal

- **metal: add col2im_1d op (f32/f16/bf16)** (#25176, `f36e5c3`) -- Completes
  COL2IM_1D backend coverage (CPU/CUDA/Vulkan already had it). Gather kernel with one
  thread per output element, F32 accumulator, no atomics.

## Vulkan

- **vulkan: fix 32-bit integer overflow in CEIL_DIV** (#25245, `86961ef`) -- Silent
  overflow bug in dispatch macro; safe fix for large tensor dimensions.

## CPU / Platform

- **ggml-cpu: use UE4M3 LUT in ARM NVFP4 dot product** (#25331, `20a04b2`) -- ARM
  NVFP4 accuracy improvement using a lookup table for the UE4M3 format.
- **ggml-cpu: enable tiled matmul on AIX** (#25199, `3b4fca1`) -- Reduces stack buffer
  sizes to avoid AIX segfaults in the tiled path; reports ~2x PP speed gains for FP32,
  Q4_0, and Q8_0 on Power10.
- **common: set optimal default thread count for ppc (Linux + AIX)** (#25237, `ee445f9`)
  -- Fixes oversubscription on SMT4/SMT8 Power systems by using
  `physical_cores * min(smt_factor, 2)` instead of raw `hardware_concurrency()`.

## Server / API

- **server: fix deadlock in load_models() when erasing a finished download** (#25358,
  `9abce74`) -- Download monitoring thread acquired the models mutex on exit while
  `load_models()` held it during `erase()`; moved join outside the lock via
  `threads_to_join`.
- **server: temporary skip model downloading API test** (#25355, `bfdf581`) -- CI
  workaround pending investigation; test will be re-enabled once root cause is fixed.

## UI

- **ui: restore Ctrl+B sidebar toggle shortcut** (#25307, `d80e878`) -- Shortcut was
  dropped in a prior refactor; restored in the Svelte navigation component.
- **ui: fake 200 for proxy DELETE req** (#25298, `898b088`) -- Proxy DELETE responses
  are now handled client-side; fixes MCP tool compatibility.

## Build / Scripts

- **scripts: use HF_TOKEN when downloading UI assets** (#25280, `4871961`) -- Passes
  `HF_TOKEN` to the asset download step to benefit from higher Hugging Face rate limits.
