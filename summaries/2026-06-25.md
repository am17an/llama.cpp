# llama.cpp daily summary -- 2026-06-25

Active day with 10 commits across Vulkan, Hexagon/NPU, the web UI, and model support. The biggest change is a major Qualcomm Hexagon matmul overhaul; the Vulkan backend also received two correctness fixes worth noting for anyone seeing GPU device timeouts or silent broken shader builds.

## Vulkan/GPU

- **vulkan: apply bias before softmax in FlashAttention to avoid overflow** (#24909, `ac4105d`) -- correctness fix; FP overflow was possible when bias was applied after softmax.
- **vulkan: fail the build when a shader fails to compile** (#24450, `1191758`) -- previously a non-zero compiler exit with empty stderr silently produced a broken backend; now the build aborts.
- **vulkan: allow reducing graph submission batch size to avoid device timeouts** (#24872, `51eae8c`) -- adds `GGML_VK_MAX_NODES_PER_SUBMIT` env var; fixes driver-level timeouts seen on some iGPUs during image generation.

## Hexagon / NPU

- **hexagon: major MUL_MAT and MUL_MAT_ID rework** (#24954, `8be759e`) -- 32x32 tiled weight repack, HMX/HVX kernel unification, graph caching to skip recomputing kernel params, and improved VTCM allocation. Drops support for Hexagon arch < v73 (HMX now required). Large change with potential perf and compatibility impact on Qualcomm HTP targets.

## Web UI / Server

- **ui: new logo + navigation cleanup & mobile UI/UX overhaul** (#24897, `ef9c13d`) -- replaces shadcn sidebar with a custom component, adds a PWA standalone-detection store, rewrites mobile scroll/auto-scroll logic, and adds a dedicated mobile `/search` route. Broad surface-area change.
- **ui: pulsing model load progress bar below model picker** (#24931, `00139b6`) -- visual follow-up; bar shown on both desktop dropdown and mobile sheet triggers.
- **chat: harden capability caps check** (#24973, `09cedfd`) -- tightens the caps validation logic in the chat path.

## Models

- **model: add LFM2.5-ColBERT-350M and LFM2.5-Embedding-350M** (#24913, `88636e1`) -- Liquid AI embedding and ColBERT models now recognized.
- **mtmd: unlimited-ocr model converter + parity test** (#24969, `894bb27`) -- adds converter script and a parity test for the unlimited-ocr multimodal model.

## Cleanup

- **common: remove unused json-partial** (#24968, `fb40104`) -- dead code left over from the old minja system; no behavior change.
