# llama.cpp daily summary -- 2026-07-26

Active day with 11 commits merged. The headline addition is full MCP stdio support in the server (a substantial ~2680-line feature), alongside bug fixes across common utilities, hexagon backend, and build infrastructure.

## API/server

- **MCP stdio support**: server now supports spawning and communicating with external MCP servers via stdio (`--mcp-servers-config`/`--mcp-servers-json`). MCP tools are exposed through `/tools` and chat completions as `<server>_<tool>`. Includes hardened transport (polled pumps to prevent grandchild deadlock), Windows PATHEXT resolution, and a 21-test suite. (#26062, `20455a4`)
- **datetime tool format arg**: added `format` argument to the built-in datetime tool for flexible output formatting. (#26117, `abc3487`)
- **Missing generation_settings params**: `adaptive_target` and `adaptive_decay` were missing from the task JSON serialization; now fixed with a regression test. (#25830, `2cfc767`)

## Common/sampling

- **Reasoning budget sampler multi-sequence**: refactored trie/AC automaton into a separate file (`common/trie.cpp`) and extended the reasoning budget sampler to support multiple end sequences; end-sequence tokens are now replayed on budget exhaustion. (#25544, `910196f`)
- **LoRA use-after-free fix**: one-line fix removing a dangling reference when LoRA adapter loading fails. (#25611, `8bb9093`)
- **Skip empty implicit default preset**: INI parser was creating an empty implicit default section even after reserved keys were stripped; now skipped to avoid phantom entries in router mode. (#25643, `c812c54`)

## Hexagon

- **Partial im2col support**: adds `IM2COL` op targeting patch-embedding convolutions on Qualcomm HTP, including local VTCM layout computation. (~346 lines new C). (#26007, `355303e`)

## Build/CI

- **WebGPU WASM fix**: separated WASM build into its own workflow and disabled OpenMP for Emscripten compatibility. (#25943, `7cdd557`)
- **cpp-httplib 0.51.0**: vendor update. (#26067, `720d7fa`)

## Fixes/misc

- **gguf virtual destructor**: `gguf_writer_base` destructor marked `virtual` to prevent silent base-only destruction through pointer-to-base. (#25867, `fb92d8f`)
- **test-save-load-state sync**: added synchronization to prevent non-determinism in save/load state generation tests. (#26056, `d67c0b4`)
