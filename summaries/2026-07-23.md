# llama.cpp daily summary -- 2026-07-23

A busy day with 15 commits merged: notable GPU work across CUDA, WebGPU, and Hexagon; a new model family (Poolside Laguna); a cluster of DeepSeek4 template fixes; UI additions; and -- most significantly -- a policy reversal that now permits fully AI-generated code as long as contributors fully understand and own every line.

## Policy (notable change)

- **AGENTS.md/CONTRIBUTING.md: allow fully AI-generated code** -- the project no longer bans predominantly AI-generated PRs; responsibility shifts to "you must understand every line you submit, regardless of how it was produced"; undisclosed AI usage still results in a ban (#26012, 4310aa4)

## CUDA/GPU

- **NVFP4 W4A4 activation quantization improvements**: 32-byte loads, fused per-channel amax, nvfp4x4 intrinsic when available, optimized scale-search -- meaningful perf improvement for NVFP4 inference (#25730, 1a064ab)
- **GET_ROWS k-quant/i-quant/mxfp4 support on CUDA**: dequantizers factored into shared device functions and reused from a new `k_get_rows_kq` kernel; eliminates the host fallback that copied the full embedding matrix on every token (#25962, c5a4a0b)

## WebGPU

- **CONV_2D_DW (depthwise conv2d) kernel**: ported from the Vulkan backend; ops.md and WebGPU.csv updated to reflect new coverage (#25847, 7347430)

## Hexagon

- **Activation ops update**: optimized all-in-one geglu microkernel, non-contiguous source support with strided DMA for all activation ops, SILU/GELU moved to unary-ops (#25974, 0278d83)

## Models / templates

- **Poolside Laguna XS.2 & M.1 support**: GGUF conversion, chat templates, vocab handling, and auto-parser integration from Poolside's official implementation (#25165, 1f66c3c)
- **DeepSeek4 template fixes (3 PRs)**: fix crafted template to match reference reasoning-trace retention behavior (#25414, f534da2); fix APE tensor op (#25945, 67b9b0e); fix reasoning-preserve variable (#25999, e8e6c7a)

## API/Server

- **Auto-infer speculative type from draft repo sidecars**: when using `-hfd` without `--spec-type`, the first available sidecar (mtp > dflash > eagle3) is now selected automatically (#25989, 6d5a910)

## UI

- **"Default" reasoning option**: new selector value that sends nothing to the server (letting the server decide), fixing over-injection of `enable_thinking` for models that reason unconditionally (e.g. Gemma 4 E4B) (#25846, cf51256)
- **Symbolic math via nerdamer in JS sandbox**: optional user setting adds nerdamer (simplify, integrate, solve, etc.) to the sandboxed worker; vendored source, built at compile time (#25948, 61328e6)

## Build / CI / misc
