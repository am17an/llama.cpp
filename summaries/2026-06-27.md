# llama.cpp daily summary -- 2026-06-27

Active day with 19 commits to upstream/master, touching nearly every backend. The headline item is a new SSE Replay Buffer in the server, and the project bumped to version 0.15.3 following a ggml sync.

## Server / API

- **SSE Replay Buffer**: server now buffers SSE events so late-connecting clients can replay missed events (#23226, `1a87dcd`)
- **arg fix**: corrected handling of `--spec-draft-hf` and `--hf-repo-v` flags (#25043, `024930c`)
- **mtmd validations**: added stricter input validation in the multimodal layer (#25013, `b11f7c1`)

## CUDA / GPU

- **cuBLAS batched GEMM**: added `cublasSgemmBatched` mapping for HIP and MUSA vendor headers, improving cross-vendor portability (#25033, `2f18fe1`)
- **out_prod broadcast**: batch `dps2>1` path now uses `cublasSgemmBatched` for a speedup on multi-sample workloads (#24426, `f818065`)
- **SYCL softmax**: clamp input to avoid underflow in softmax (#24941, `e7e3f35`)

## Vulkan

- **MI50 optimization**: tuned `mul_mat_vecq` kernel for AMD MI50 (#22933, `487a6cc`)
- **Intel Xe1 support**: added `INTEL_XE1` arch enum and enabled coopmat1 for that target (#24404, `5a6a0dd`)
- **compiler workaround**: fixed a compiler bug triggered in the conv2d coopmat2 path (#24924, `9df0680`)

## CPU / ggml

- **SVE fix**: fixed leftover SVE path in `ggml_vec_dot_f32` that could produce wrong results on ARM SVE hardware (#24699, `c16c35b`)
- **scheduler perf**: reintroduced reduced synchronizations during split compute with corrected pipeline parallelism (#20793, `3fc4e10`)

## OpenVINO

- Updated to OpenVINO 2026.2.1 with self-contained release packages (#24974, `5397c36`)

## OpenCL

- Flush profiling batch at shutdown to avoid dropped profiling data (#25016, `5c7c22c`)

## Mamba

- Removed hardcoded 2x expansion factor in mamba2 -- now derived from model config (#23082, `960d628`)

## Build / DevOps

- `--version`, `--licenses`, and `--help` flags now work before a model is loaded (#25054, `050ee92`)

## UI

## Misc
