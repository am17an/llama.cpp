# llama.cpp daily summary -- 2026-08-13

Active day with 18 commits across multiple subsystems. Highlights include Vulkan gaining ternary (TQ2_0) support, a significant server feature for slot persistence with media, semantic versioning added to the CMake build, a new system-level config file mechanism, and several CI fixes including temporary ROCm disablement.

## Server / UI

- **server**: support slot save/restore with media inputs (#26640, `5d9e5ac`) -- slots can now persist state including images/audio across API calls.
- **ui**: add `read_media` tool to the built-in chat UI (#25877, `4dd1275`).

## Vulkan / GPU

- **vulkan**: add TQ2_0 (ternary) support (#25850, `a7cd2f0`) -- first Vulkan ternary quantization type; adds dequant, mul_mat_vec, and matmul via dequant_funcs shaders. Targets larger BitNet models.

## OpenCL

- **opencl**: default FlashAttention c8 cluster width to 16 on Snapdragon X1E for better performance (#26433, `89e0aa6`).
- **opencl**: fall back to flat mv q5_k when weight exceeds `image1d_buffer_t` limit (#26880, `cb27fe9`).

## AArch64 / CPU

- **kleidiai**: add runtime feature detection for AArch64 CPU capabilities; replaces compile-time assumptions with dynamic dispatch (#26076, `132753b`).

## Build / CMake

- **cmake**: introduce semantic versioning for llama.cpp releases; includes a new `make-release` CI workflow (#26839, `680a9ae`).
- **cmake**: add CMake config-version support (ggml/1582, `13fd0bb`).

## Config / Common

- **common**: add system-level config file (INI); precedence order is CLI > ENV > system/user config (#26118, `8e7f22b`). Covers Linux/Mac (`/etc/llama.cpp/config.ini`, `~/.config/llama.cpp/config.ini`) and Windows (`%PROGRAMDATA%`, `%APPDATA%`).

## Fixes / Hardening

- **gguf**: harden loader against malformed tensor dims and metadata types; fixes SIGFPE on zero-dim tensors (#25596, `d8a8bea`).
- **model**: disallow integer `dflash` `sliding_window_pattern` to prevent misconfiguration (#26900, `ece98b8`).
- **wavtokenizer-dec**: bound `posnet`/`convnext` block_count against `n_layer_all` to prevent OOB (#26892, `55f453b`).

## Conversion

- **convert**: handle `per_layer_config` in Gemma4 for transformers 5.15 compatibility (#26882, `6eff593`).

## CI

- ROCm CI temporarily disabled: release workflow and build cache updated (#26969 `9558fa4`, #26962 `7a9ff95`).
- Thread sanitizer CI fixed; ccache removed from sanitizer builds (#26927, `84e908c`).

## Misc

- **tests**: update speculative decoding params (#26925, `a4a4c51`).
- **sync**: ggml upstream sync (`af05a42`).
