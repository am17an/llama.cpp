# llama.cpp daily summary -- 2026-06-22

Today's 11 commits were dominated by server infrastructure work -- real-time model load progress, batch construction refactoring, and multimodal memory tracking -- alongside two significant PEG/grammar parser improvements and a notable new speculative decoding feature for Step3 MTP flash models.

## Speculative Decoding

- **Step3.5/3.7 flash MTP3 support** (#24340, `d789527`): Adds `mtp_layer_offset` and multi-head speculative draft/process for Step3 flash MTP models. Introduces `llama_set_mtp_layer_offset` and `llama_model_n_nextn_layer` API calls; reworks `speculative.cpp` to handle chain-heads across multiple MTP blocks.

## API / Server

- **Real-time model load progress via `/models/sse`** (#24828, `d6d8995`): New SSE endpoint streams load progress events while a model is loading, enabling responsive UIs without polling.
- **Batch construction refactor** (#24843, `bddfd2b`): Large refactor of `server-context.cpp` (+534/-302); introduces `abort_all_slots` and more careful batch-full handling.
- **Fix spec model load progress reporting; add `stages` list** (#24870, `7c082bc`): Corrects progress reporting for speculative (draft) models and adds a `stages` field to the SSE load events.
- **Add `verbose` field to request schema** (#24864, `bfa3219`): Allows clients to request `__verbose` timing info on a per-request basis without starting the server with `--verbose`.

## mtmd (Multimodal)

- **Add load progress callback** (#24865, `2f89acc`): Exposes a callback in `clip.h`/`mtmd.h` so callers can track multimodal model loading progress.
- **Fix `mtmd_get_memory_usage`** (#24867, `0d135df`): Corrects memory usage reporting in the CLIP/mtmd layer.

## Jinja / Templates

- **Implement `call` statement** (#24847, `bf53382`): Adds Jinja2-compatible `call` blocks to the jinja runtime, with tests.

## PEG / Grammar

- **Refactor GBNF `until` grammar generation** (#24839, `063d9c1`): Rewrites the `until` grammar rule using an Aho-Corasick automaton for correctness with multi-string patterns; adds regression tests.
- **Implement AC parser for stricter grammar generation** (#24869, `52b3df0`): Extends the PEG parser with an AC-based parser mode producing stricter GBNF grammars; refactors auto-parser generator accordingly.

## Misc
