# llama.cpp daily summary -- 2026-06-20

A busy day dominated by server refactoring and multimodal bug fixes, with 17 commits landed to upstream/master. Highlights include a significant server communication refactor, a 12x speedup in token probability sorting, eagle3 speculative decoding for Qwen3.5/3.6 models, and several Windows/multimodal correctness fixes.

## API / Server

- **Refactor child-to-router communication** -- restructured inter-process signaling in multi-child server mode, adds docs to README-dev.md (#24821, `2b686a9`)
- **Optimize `get_token_probabilities`** -- switch from full sort to `std::partial_sort` for top-n logprobs; ~12x faster on 128k-vocab models (704 us vs 8556 us per call) (#24796, `4b48a5`)
- **Add `--agent` CLI arg** -- new flag for agent mode, cleans up legacy `webui` naming compat shims (#24801, `8c2d6f6`)
- **Remove internal "webui" references** -- cosmetic cleanup to drop deprecated naming in code and tests (#24817, `175147e`)
- **Fix ctx-shift `n_discard` unbounded** -- bug where context shifting could discard more tokens than intended (#24786, `159d093`)
- **Consolidate slot selection** -- `get_available_slot` absorbs `get_slot_by_id`; single function handles both targeted and LCP-based slot lookup (#24755, `80452d6`)
- **Comment support in `--api-key-file`** -- lines starting with `#` are now ignored in API key files (#23168, `fabde3b`)

## Multimodal (mtmd)
