# llama.cpp daily summary -- 2026-06-14

Nine commits landed today, dominated by a major server/UI static-asset overhaul and the addition of the cohere2-MoE architecture. Vulkan received a significant shader consolidation that extends non-contiguous tensor support, and the Jinja template engine got two correctness fixes.

## Model support

- **cohere2-MoE architecture** (#24260, `4988f6e`) -- Adds full GGUF conversion and inference support for Cohere Command-style MoE models (cohere2moe). Introduces ~443-line `cohere2moe.cpp`, iSWA sliding-window attention, sigmoid expert selection, and LayerNorm support. Notable new architecture addition.

## Vulkan / GPU

- **Non-contiguous unary/GLU op support** (#24215, `1a7718b`) -- Consolidates all Vulkan unary activation shaders (abs, elu, gelu, silu, tanh, etc.) into a single `unary.comp` using per-element stride-aware indexing via fastdiv. Large shader refactor (~7500 insertions, ~4900 deletions); adds `expm1` op as well.

## Jinja / templates

- **Fix negative-step slice with explicit start/stop** (#24580, `f05cf46`) -- Corrects slice iteration when step is negative and both bounds are given; adds regression tests.
- **Fix `split` and `replace` with empty first argument** (#24574, `341babc`) -- Guards against zero-size delimiters causing incorrect splits or infinite loops; adds tests.

## UI / server

- **Clean up static asset handling** (#24550, `57fe1f0`) -- Refactors how the HTTP server discovers and serves embedded UI files; bundles UI assets into an archive, simplifies CMake logic, and updates CI workflows.
- **Keep original file name and path** (#24568, `597b667`) -- Reworks `ui/embed.cpp` so embedded asset paths match the original build-output names, replacing custom post-build renaming logic.
- **Build-time gzip compression** (#24571, `e8067a8`) -- Compresses UI assets at CMake build time and teaches the server to serve `Content-Encoding: gzip` responses, reducing transfer size.
- **Fix llama-ui-embed crash when no asset dir given** (#24597, `53bd47e`) -- Null-checks the asset directory path before use, preventing a crash when the embed tool is invoked without arguments.

## Core / misc

- **Wrap `llama_device_memory_data` in fit** (#24522, `d8a24cc`) -- Encapsulates device memory data behind a wrapper in `fit.cpp/h`, reducing direct exposure to internal memory structures in the server context.
