# llama.cpp daily summary -- 2026-07-16

A busy day across all GPU backends: 20 commits landed covering CUDA, SYCL, Metal, OpenCL, Vulkan, and the server UI. The most notable additions are a SYCL Flash Attention path accelerated by Intel's oneDNN XMX engine (up to 4x faster at long contexts on Battlemage) and a new CUDA LIGHTNING_INDEXER op with both a generic vector kernel and a Tensor Core (WMMA) kernel. Several Adreno OpenCL regressions were also patched.
