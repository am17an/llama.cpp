# llama.cpp daily summary -- 2026-07-27

Today was dominated by the landing of full MiniMax-M3 support -- both the sparse-attention text model and vision tower -- after several weeks of review. A handful of UI fixes and a new subprocess abstraction also landed.

**Note: existing MiniMax-M3 GGUFs must be regenerated** due to the indexer tensor rename.

## Model support

- **MiniMax-M3 text (MSA)**: Full support for MiniMax-M3 with MiniMax Sparse Attention landed (#24908, `b1d4c65`). MSA selects only the top-16 key blocks per GQA group, so decode attention cost is fixed (~2048 KV budget) regardless of context length. Requires flash attention; dense fallback available with quality warning. Context shift disabled. Adds per-layer indexer KV cache. This is a notable new feature and a large diff (~1100 lines).
- **MiniMax-M3 vision**: mmproj / clip vision tower added for MiniMax-M3-VL -- 3-axis (T/H/W) RoPE, gate-less GELU-erf FFN, two-stage patch-merge projector (#25113, `3d1c3a8`).
- **MiniMax-M3 indexer tensors at F32**: Keeps indexer projections at F32 during quantization for speed and accuracy -- block selection is sensitive to quant error (#26144, `7657a6c`).
- **GLM-5.2-Vision**: mtmd vision support added for GLM-5.2-Vision via the kimivl conversion path (#26126, `af28502`).

## Build / common

- **subproc.h wrapper**: New `common/subproc.h` abstracts subprocess spawning; disabled by default on Android, iOS, and WASM (sandboxed envs). Disabling subprocess also disables MTMD video support (#26102, `d2a8182`).
- **mtmd android build fix**: Guard unused param when subprocess / video support is off (#26150, `0d47ea7`).

## UI / server

- **Conversation import format detection**: iOS has no UTI for `.jsonl`, causing the picker to grey out exported conversations. Import now detects format from file contents (ZIP magic, JSONL session record, or legacy JSON). Also fixes misleading import summary reporting (#26121, `55b7d6c`).
- **System message edit box**: Auto-resize on input and on open; added max-height to cap growth (#26006, `d4d057b`).
- **Context gauge card regressions**: Restored text-sm/ring classes and per-token monitoring; conversation routing now pins scroll until page height settles (#26099, `ff067f7`).
- **Symbolic math sandbox prompt**: Corrected nerdamer usage and warnings in JS sandbox constants (#26131, `88b47a7`).

## OpenCL

- **Fused RMS norm mul view offset fix**: Corrected off-by-one view offset in fused RMS norm (#26085, `42fc243`).
