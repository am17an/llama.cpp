# llama.cpp daily summary -- 2026-08-16

A busy day headlined by the long-awaited Kimi-K3 architecture landing, alongside a server threading redesign, Vulkan Intel Xe tuning, dependency bumps, and several smaller fixes. The --mmap/--no-mmap flags are now officially retired in scripts and docs in favour of --load-mode.

## New Models

- **Kimi-K3 text model** (#26185, ad1de39) -- major new architecture from Moonshot AI: hybrid KDA (linear) + MLA (full) attention, latent MoE, situ activation (replaces SwiGLU), MXFP4 expert weights with lossless repack (no bf16 round-trip), cross-layer residual attention, and an MLA output gate. Includes converter (`conversion/kimi_k3.py`), chat template with reasoning/tool-call parsing, and test fixtures. MXFP4 depack shares infrastructure with DeepSeek-V4. Metal/Vulkan fall back for the cross-layer residual op until those kernels land. `LLAMA_MAX_EXPERTS` bumped from 512 to 1024.

## Server / API

- **yield_to_queue thread model redesign** (#27133, 22b8e31) -- swaps the worker/main-thread design and moves `common_speculative_process` into the worker; cleaner concurrency, no user-facing API change.
- **--models-dir now loads MTP assistant models** (#24431, 5f754ea) -- `common/preset.cpp` uses a strict prefix check to auto-discover draft models when `--models-dir` is set.

## Vulkan / GPU

- **Intel Xe coopmat1 shared-memory tuning** (#25380, 9b0a2ce) -- adds `SHMEM_STRIDE_PAD` and `APPLY_SLM_A_RESHAPE` for mul_mm on Intel Xe; SLM-A reshape restricted to Intel Windows driver to avoid OOB reads; fixes shmem estimate for the `SHMEM_STRIDE_PAD=0` case.
- **Intel driver gating fix** (7b38cb7) -- corrects the conditional logic for blacklisting a problematic driver version; trivial indent cleanup (6b4344e) landed alongside.

## Fixes

- **GGUF array type check** (#27075, 27df919) -- validates the array element type before reading in the model loader, vocab, imatrix loader, and clip; prevents a class of malformed-file crashes.

## Build / Docs / Deprecations

- **--mmap/--no-mmap -> --load-mode migration** (#26934, 0177dcc) -- replaces the deprecated flags with `--load-mode` across SYCL examples, Snapdragon scripts, bench scripts, and all README/docs. **Action needed** if you have custom scripts using `--mmap`, `--no-mmap`, `--mlock`, or `--direct-io`.

## Vendor

- **cpp-httplib bumped to 0.53.1** (#27103, 77140d2)
- **BoringSSL bumped to 0.20260813.0** (#27099, adb55e5)

## UI / Web

- **API key field masked** (#26562, ece963f) -- marks the key as a private/password field so browsers do not autofill or offer to save it; `isPrivate` flag is now part of the settings-registry type so future fields can opt in.
- **MCP structuredContent fallback** (#26691, 0d9ceae) -- reads `structuredContent` from MCP tool results when `content` is empty.
